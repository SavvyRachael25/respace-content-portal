For the dev

Posting checklist

Each HTML file is self-contained with inline CSS, font imports, and JSON-LD schema in the head. The dev can drop them straight into the blog system, or extract the body content into the existing CMS template.

Option A · Drop in as-is

If the blog system supports raw HTML pages, upload each file directly to the right slug:

  • Post 1: /blog/in-the-news/realtor-com-features-respace-co-homeownership/
  • Post 2: /blog/homebuying-tips/cohousing-affordable-housing-crisis-co-homeownership/
  • Post 3: /blog/homebuying-tips/co-living-vs-co-homeownership-seattle/
  • Post 4: /blog/homebuying-tips/how-to-buy-house-with-friends-llc-co-homeownership/

Each canonical tag and breadcrumb schema is already pointing at the correct production URL.

Option B · Extract into CMS

If the blog uses a CMS template, extract these from each file:

  • Title, meta description, canonical URL, OG / Twitter tags from the <head>
  • All three (or four) JSON-LD <script> blocks
  • Article body from inside <article class="article">
  • FAQ section from <section class="faq-section">

Keep the JSON-LD blocks intact. They are the AEO and GEO engine.

After publish

Google Search Console submission protocol

Once each post is live, run this protocol to accelerate indexing. About 4 minutes per post. Run by Mary or whoever owns publishing.

01
Confirm the post is live
Open the URL in incognito. Verify rendering, JSON-LD in head, phone link works, canonical matches.
02
Validate schema
Run through Google Rich Results Test. Article, FAQPage, BreadcrumbList must all parse. (Plus HowTo for Post 4.)
03
Open Search Console
Navigate to the respace.co property. Confirm ownership is verified.
04
URL Inspection
Paste the new post URL. New posts return "URL is not on Google."
05
Test Live URL
Wait 30 to 90 seconds. Confirm indexable, mobile-usable, structured data detected.
06
Request Indexing
Adds the URL to the priority crawl queue. Indexing usually completes in hours.
07
Update sitemap
Confirm respace.co/sitemap.xml includes the new post. Resubmit sitemap if multiple URLs added.
08
Bing Webmaster Tools
Submit each URL to Bing in parallel. Bing powers ChatGPT search; faster pickup means faster generative engine results.
